\section{Data and Methods}\label{sec:methods}

- Using 4 year periods for analysis - having more data and less one-year variances and having 3 years left if one discipline not enough data

- Using the top 35 - having enough data, even if some disciplines (for example Womens Adults 3000m Steeplechase 2001)

- Age groups; U18, U20, Adults - most relevant and with consistent data (U23 is a "transition" age group, also mostly only top 30 collected or less data available)
- for every group:
    - Data Start period (always 2001-2004)
    - End period (for plot x 2021-2024)
    - One data pool of all data points of the periods for the specified group: f.e. all data: all disciplines, gender and age groups

- Mean and Std os calculated over all data points per period
- Percentage diff (maybe with math) of mean and percentage diff (maybe with math) of std
- to test if the means of the two populations are equal -> Welch's t test
- to test if population variances are equal -> Levene's Test
- Cohen's d for effect size

FOR RANK Analysis:

- Calculation of the mean per rank per group per period
- calculation of the difference of the two periods per rank per group
